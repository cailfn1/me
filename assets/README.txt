drop these files in this folder to customize the site:

  avatar.png      -> profile picture (square, ~200x200 works great)
  wallpaper.jpg   -> full-page background image (1920x1080 or higher)
  music.mp3       -> audio track for the music widget

filenames matter — they're referenced directly from index.html and style.css.
no other steps needed; just refresh the page after dropping a file.

to use a different wallpaper filename, edit body::before in style.css.
to use a different music filename, edit the <audio src="..."> in index.html.
